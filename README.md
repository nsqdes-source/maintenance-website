# Maintenance Website

واجهة الموقع التشغيلي لمنصة خدمات الصيانة.

## الهدف
موقع بسيط وسريع لعرض خدمات الصيانة، الأعمال المنفذة، استقبال طلبات الخدمة، ووسائل التواصل.

## النطاق الأولي
- الصفحة الرئيسية
- الخدمات
- الأعمال المنفذة
- طلب خدمة
- تواصل معنا

## التقنية
- Next.js
- React
- Tailwind CSS
- Supabase
- Vercel

## ملاحظة معمارية
هذا المستودع مستقل عن `maintenance-platform`، مع إمكانية التكامل مع قاعدة بيانات Supabase المشتركة وفق حدود واضحة.
